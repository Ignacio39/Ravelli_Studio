# Ravelli Studio Website Specification

## Nombre del proyecto

Ravelli Studio

Subtítulo de marca:

"Desarrollo Web y Soluciones Digitales"

Marca personal:

"Ravelli Studio by Ignacio Ravelli"

---

# 1. Objetivo del proyecto

Crear una página web profesional para presentar y vender servicios de desarrollo web.

La página debe funcionar como portfolio comercial de un desarrollador freelance, transmitiendo confianza, profesionalidad y capacidad técnica.

El objetivo principal es convertir visitantes en potenciales clientes interesados en contratar:

- Landing pages.
- Páginas web profesionales.
- Soluciones digitales personalizadas.

La web debe estar orientada al cliente, enfocándose en beneficios y resultados, no en mostrar tecnologías.

---

# 2. Modelo de negocio e identidad

Ravelli Studio no debe parecer una gran agencia, sino un estudio profesional independiente donde el cliente tiene contacto directo con el desarrollador.

Imagen buscada:

- Profesional.
- Moderna.
- Tecnológica.
- Cercana.
- Confiable.

Evitar:

- Apariencia de empresa corporativa gigante.
- Diseño demasiado informal.
- Estética de hacker.
- Exceso de efectos visuales.

---

# 3. Público objetivo

Clientes principales:

## Pequeños negocios

Ejemplos:

- Restaurantes.
- Talleres.
- Comercios.
- Servicios locales.

## Profesionales independientes

Ejemplos:

- Arquitectos.
- Consultores.
- Emprendedores.
- Especialistas.

## Proyectos digitales

Ejemplos:

- Startups pequeñas.
- Nuevos emprendimientos.

---

# 4. Servicios ofrecidos

No mostrar precios públicos.

Todos los servicios deben tener un botón:

"Solicitar presupuesto"

La cotización será personalizada según las necesidades del cliente.

---

## Servicio 1: Landing Page

Descripción:

Página web simple y profesional para negocios que necesitan comenzar su presencia digital.

Incluye:

- Diseño moderno.
- Adaptación a celulares.
- Información del negocio.
- Servicios.
- Botón de WhatsApp.
- Ubicación.
- Llamadas a la acción.

---

## Servicio 2: Web Profesional Básica

Descripción:

Una página más completa para negocios que necesitan transmitir mayor confianza.

Incluye:

- Página de inicio.
- Información del negocio.
- Servicios.
- Galería.
- Contacto.
- Redes sociales.
- Preguntas frecuentes.

---

## Servicio 3: Web Profesional Avanzada

Descripción:

Una solución visual más completa para empresas o marcas que buscan destacar.

Incluye:

- Diseño personalizado.
- Más secciones.
- Animaciones.
- Mejor experiencia de usuario.
- SEO básico.
- Portfolio.
- Integraciones externas.

No incluye:

- Panel administrativo.
- Gestión interna de usuarios.
- Sistemas complejos.

# 6. Diseño visual

Estilo:

Combinar:

- Minimalista tecnológico.
- Oscuro profesional.

Inspiración:

- Empresas modernas de software.
- Estudios tecnológicos.
- Productos digitales premium.

---

## Colores

Usar:

- Fondo oscuro elegante.
- Tonos grises.
- Contrastes claros.
- Un color de acento tecnológico.

No usar demasiados colores.

---

## Tipografía

Debe transmitir:

- Modernidad.
- Legibilidad.
- Profesionalidad.

---

# 7. Experiencia visual

Agregar animaciones modernas pero discretas.

Incluir:

- Aparición suave al hacer scroll.
- Transiciones CSS.
- Hover en botones.
- Animaciones ligeras en tarjetas.

Evitar:

- Animaciones excesivas.
- Elementos que distraigan.
- Efectos pesados.

La página debe cargar rápido.

La página debe funcionar correctamente en:

- Celulares.
- Tablets.
- Escritorio.

---

# 11. SEO básico

Agregar:

- Meta etiquetas.
- Títulos correctos.
- Descripciones.
- Texto optimizado.
- Etiquetas semánticas HTML.

Preparar la web para posicionamiento futuro.

---

# 12. Internacionalización futura

La página estará en español inicialmente.

Preparar estructura para agregar inglés posteriormente.

No implementar traducción todavía.

---

# 13. Enfoque de comunicación

La web debe vender soluciones.

NO destacar:

- Lenguajes.
- Frameworks.
- Herramientas.

SÍ destacar:

- Diseño profesional.
- Presencia digital.
- Mejor imagen del negocio.
- Facilidad de contacto.
- Soluciones personalizadas.

---

# 14. Requisitos finales

La web debe ser:

- Profesional.
- Rápida.
- Moderna.
- Fácil de modificar.
- Compatible con hosting gratuito.
- Lista para agregar nuevos servicios en el futuro.

Crear código limpio, organizado y documentado.
